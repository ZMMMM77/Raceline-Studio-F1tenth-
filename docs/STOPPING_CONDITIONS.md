# 运行截止条件

在「车辆与约束 → 运行截止条件」里设置：

- 最大求解时间：默认 300 秒，允许 1–3600 秒。包括粗网格初始化及所有精度阶段。
- 停滞检查窗口：默认 50 次，允许 5–400 次迭代。
- 窗口内最小改善：默认 0.10%，允许 0–5%。填 0 可关闭停滞停止。

停滞检查比较同一精度阶段内的最佳可行目标值，连续可行迭代达到窗口长度、改善不足阈值时尝试结束。切换精度时窗口重置；不满足采样约束的迭代会清空窗口。粗网格初始化只受时间限制，不因停滞结束整个求解。

时限采用协作式检查：在求解器下一次调用目标函数、约束函数或迭代回调时停止。一次底层数值运算不能被中途抢占；最后的加密验证、绘图和文件保存可能额外用时，因此这不是严格的进程终止计时器。

停止后仍检查曲率、整车包络加余量、地图距离、前进方向、闭环和自交。候选路线未通过检查就不导出。通过检查的提前停止结果显示「提前停止 · 加密检查通过」，表示可行路线，不能解释为求解器已经收敛或获得全局最优。

report.json 中新增：converged、feasible、stopped_early、stop_reason、stop_message、elapsed_seconds、max_runtime_s、plateau_window、plateau_percent。stop_reason 可为 solver_converged、plateau 或 time_limit。迭代计数包含粗网格初始化。

## 更新后启用

保存当前需要的结果，关闭原服务终端里的运行任务（Control+C），重新打开「start.command」，然后刷新浏览器并重新导入地图。已经开始的旧任务不会热更新为新停止规则。
